# Lagindelning-app

Ett verktyg för att hålla koll på spelare i ett lag och ge dem en nivå (grön/gul/röd). Slumpa lag och nivåindela snabbt och enkelt.

## Backend krävs

Appen hämtar data från [Lagindelning-api](https://github.com/bigbossalex11-coder/Lagindelning-api). Starta det först enligt dess README, sedan appen nedan.

## Köra lokalt

```
git clone https://github.com/bigbossalex11-coder/Lagindelning-app
cd Lagindelning-app
npm install
npx expo start
```

Appen är testad i Expo Go på iPhone och i en Android-emulator (Pixel 10a) i Android Studio.

## Öppna appen

Telefon: Installera Expo Go och skanna QR-koden. Telefonen och datorn måste vara på samma wifi.

Emulator: Starta en emulator (till exempel i Android Studio) och tryck `a` i terminalen, eller `i` för iOS-simulatorn på Mac.

Appen hittar datorns adress automatiskt, så ingen IP-adress behöver ändras.

## Vid problem med uppkopplingen

Når inte appen servern? Kontrollera att Windows-nätverket är inställt som Privat,
eller koppla datorn och telefonen till samma mobila hotspot.
